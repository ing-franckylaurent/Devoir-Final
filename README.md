Concevoir un site web touristique sur la ville de Jacmel Vous êtes chargé de réaliser un site web statique visant à promouvoir la ville de Jacmel, reconnue pour son patrimoine culturel, son carnaval, ses plages, son artisanat et son architecture. Le site doit être moderne, responsive et offrir une expérience utilisateur agréable. Objectifs À travers ce projet, l'étudiant devra démontrer sa capacité à :  Structurer une page web avec HTML5 ;  Mettre en forme un site avec CSS3 ;  Ajouter des interactions avec JavaScript ;  Concevoir un site responsive adapté aux ordinateurs et aux téléphones.
